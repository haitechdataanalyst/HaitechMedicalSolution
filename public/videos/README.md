# `videos/` — video files

`home-hero/` holds the three home page hero slides. Each slide has three files: `hero-<n>-1080.mp4` (wide screens), `hero-<n>-540.mp4` (phones) and `hero-<n>-poster.jpg` (shown while the video loads).
`home-hero/source/` keeps the 4K originals the slides were encoded from; the site does not play them.
