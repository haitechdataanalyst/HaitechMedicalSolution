# `images/` — photographs and illustrations

| Folder | Holds |
|---|---|
| `site/` | Images that belong to the website itself: `hero/` (home page slides) and `placeholder.svg` (shown wherever a product image is missing) |
| `articles/` | Pictures used inside the support articles |
| `team/` | Team portraits, named `<first>-<last>.jpg` (see its README for the size and crop) |
| `icons/` | Custom SVG icons |
| `products/` | Everything that is sold, one folder per brand: [`products/README.md`](products/README.md) |
