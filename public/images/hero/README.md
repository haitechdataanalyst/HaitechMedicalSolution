# Hero Images

This directory contains background images for the hero carousel on the homepage.

## Required Images

Please add the following three images:

1. **medical-equipment-1.jpg** - Main medical/dental equipment showcase
   - Recommended size: 1920x1080px
   - Shows general medical/dental equipment or workspace

2. **dental-loupes-2.jpg** - Dental loupes focus
   - Recommended size: 1920x1080px
   - Highlights dental loupes or magnification systems

3. **led-headlights-3.jpg** - LED headlights focus
   - Recommended size: 1920x1080px
   - Features LED headlight technology

## Image Guidelines

- **Format**: JPG, JPEG, or WebP
- **Dimensions**: 1920x1080px (16:9 ratio) or higher
- **File size**: Optimize images to under 500KB each for better loading performance
- **Content**: Images should have enough contrast to allow white text overlay to be readable
- **Quality**: Use high-quality, professional images that represent the brand

## Tips

- Images will have a gradient overlay applied to improve text readability
- The left side of images is more important as that's where the text appears
- Consider the color palette - teal/blue tones work well with the brand colors
