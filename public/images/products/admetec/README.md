# `admetec/` — Admetec products

Named after the site's own categories.

| Folder | What it is |
|---|---|
| `loupes/` | Galilean, Prismatic, Ergo and Ergo V loupes, with one photo per frame and colour: [`loupes/README.md`](loupes/README.md) |
| `lights/` | LED headlights: `wireless/` (Butterfly family) and `wired/` (Orchid family); a folder per model, plus the series photos beside them |
| `camera/flamingo/` | The Flamingo loupe camera: `product/` (cut-out product shots) and `photography/` (photo shoot) |
| `frames/` | The frame range itself, without loupes: `our-frames/<frame>-frame/` and `thumbnails/<frame>-frame-thumbnail.jpg` (one picture per frame) |
| `brand/` | Brand banner |
